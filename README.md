# Nahr CRM · frontend

Учебный проект школы арабского языка. Парная часть проекта находится в репозитории [crm-backend](https://github.com/ada245287/crm-backend).

## Локальный запуск

Требуется Node.js 22 с npm.

```sh
cp .env.example .env.local
npm ci
npm run dev
```

Локальный адрес – [http://localhost:3000/login](http://localhost:3000/login). Для проверки сборки выполните `npm run build`. Собранный проект запускается через `npm start`.

## Деплой

Импортируйте репозиторий фронтенда в Vercel. Оставьте **Root Directory** равным корню репозитория. Выберите Next.js и Node.js 22. Укажите `NEXT_PUBLIC_API_URL=https://<сервис>.up.railway.app` и выполните деплой.

## Работа с демо

- Администратор и РОП видят все карточки. Менеджер видит своих клиентов, сделки, задачи и сообщения. При смене ответственного сделки, задачи и текущий чат переходят к новому владельцу. Сообщения сохраняют привязку к сотруднику на момент записи.
- Создайте клиента без выбора ответственного под администратором или РОП. При включённом автоназначении сервер выбирает участника с наименьшим числом клиентов среди получателей заявок. При равенстве используется порядок добавления сотрудников. При отсутствии получателей заявка остаётся у создателя.
- В настройках включите ночного бота и задайте период, охватывающий текущий час в Алматы. В переписке нажмите «Входящее демо» и добавьте сообщение о пробном уроке. Бот ищет ключевые слова в материалах школы, отвечает готовым текстом и оставляет чат ответственному на утро. При завершении периода сервер помечает чат новым. Входящие и ответы работают внутри демо, без внешних каналов и LLM. Обновление списка переписок происходит каждые четыре секунды.
- Выручка считается по дате перевода сделки в «Успех». День, неделя с понедельника и месяц считаются в часовом поясе Алматы. Конверсия в KPI — доля успешных среди закрытых. Проценты под графиком оцениваются по текущим этапам сделок, поэтому отражают распределение и не учитывают историю переходов.
- Расписание намаза вычисляется локально по координатам и часовому поясу выбранного города. Доступны города из встроенного списка. Выбор запоминается отдельно для каждого демо-пользователя в текущем браузере. Метод расчёта указан на экране.
- API начинает работу с 3 пользователями, 15 клиентами, 12 сделками и 10 задачами. Изменения живут в памяти процесса. Перезапуск восстанавливает исходные данные. Запускайте API в одном экземпляре для общей картины.
